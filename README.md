I built a simple responsive landing page using HTML and CSS. In the HTML file, I set up the basic HTML5 structure, linked the CSS file, and created a header with a logo and navigation links, a hero section with a heading, paragraph, and call-to-action button, a features section with three boxes, and a footer with social links. In the CSS file, I used Flexbox to lay out the header and footer, and Grid to arrange the three feature boxes in columns. I also styled the colors, buttons, and hover effects, and added a media query for screens 768px or smaller so the navigation, boxes, and footer stack vertically on mobile devices. I tested the page using the Live Server extension in VS Code by resizing the browser window to make sure it works on different screen sizes. Through this task, I learned about HTML structure, CSS layout, Flexbox, Grid, and media queries.
